
Student Performance Prediction System

1. Project Overview

The Student Performance Prediction System uses machine learning to analyze student data and predict academic performance. The project predicts a student’s final grade (G3) using demographic, social, and school-related data, so that at-risk students can be identified early.

2. Project Objectives

Analyze student academic performance.

Study the relationship between study time, absences, and grades.

Identify important factors associated with student performance.

Develop a machine learning model to predict students' final grades.

Evaluate the performance of the model.

3. Prediction Goal

The main goal is to predict the student's final grade (G3) using selected student information.

Regression: predict the exact G3 score (0–20)
Classification: predict pass/fail (G3 ≥ 10 = pass)
